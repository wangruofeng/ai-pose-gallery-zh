# 合成台多任务设计

根据用户确认，图片数量与任务并发是两个独立维度：每个任务 1–4 张，默认 1 张；允许编辑配方后继续提交不同任务，最多同时执行四个任务，其余排队。每个任务内的图片顺序调用接口。

提交时冻结参考图、提示词、模型与参数。任务结果区逐张展示排队、准备、运行、成功、失败和接口耗时，成功图片分别写入历史记录。同一任务内任意一张失败，立即停止后续图片的提交；不影响其他独立任务。

各任务在全局 Provider 内运行，路由切换不会中断。刷新不自动重新提交云端请求；ComfyUI 在提交前后分别持久化不含密钥的恢复记录。提交状态未知或跟踪中断时暂停该任务后续图片，其他任务继续运行。恢复操作只查询原任务；停止跟踪不取消后端任务，并要求在界面确认。

新记录包含任务 ID、图片序号和独立耗时。保留旧单任务的恢复入口与旧历史数据。使用受控接口测试并发、任务快照、失败隔离和恢复语义，不额外调用付费生图接口。
